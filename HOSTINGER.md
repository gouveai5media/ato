# Publicação na Hostinger

Este projeto gera uma aplicação Node.js independente em `dist/standalone`.

Na tela de configuração da aplicação web da Hostinger, use:

- Framework: `Other`
- Versão do Node.js: `22.x`
- Diretório raiz: `./`
- Comando de build: `npm run build`
- Diretório de saída: `dist/standalone`
- Arquivo de entrada: `server.js`
- Branch: `main`

O servidor usa automaticamente a variável `PORT` fornecida pela Hostinger.
